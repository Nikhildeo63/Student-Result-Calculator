Student Result Calculator 📝

A simple Python-based project that calculates a student's total marks, percentage, and grade based on marks obtained in five subjects.

Features

- Takes student name as input.
- Accepts marks for five subjects.
- Calculates total marks.
- Calculates overall percentage.
- Assigns grades based on percentage.

Technologies Used

- Python 3
- VS Code

How to Run

1. Clone this repository.
2. Open the project in VS Code.
3. Run the following command:

python main.py

4. Enter the student name and marks for five subjects.
